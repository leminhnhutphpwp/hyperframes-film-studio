# Sound effects

Put sound files you have the right to use here, one folder per sound, and name them in a chapter's `"sfx"` list
(`templates/film/shared/chapter_build.py` converts them into the chapter). Good free sources: Pixabay sound effects,
Freesound (check each file's licence and credit line). `tools/synth_audio.py` can also generate simple sounds.

Audio files are not committed (`.gitignore`); keep a note of each file's source and licence next to it.
